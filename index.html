      Questions

      What is Suchi?
      A standalone terminal (TUI) workspace for Linux that combines clipboard history, a short-notes scratchpad, and system-wide text expanders in one binary.
      How do I install it?
      Run the install script from the repository, then launch it with suchi. Check the background daemon with systemctl --user status suchi-daemon.service.
      Which systems does it support?
      Modern Linux distributions, tested on Debian 12. No desktop-environment extensions are required.
      How do I navigate it?
      Vim-style modal keys: Tab switches workspaces, j/k moves, / searches, p pins, d deletes, y copies, and ? opens help.
